# Roadmap

## Prototype hardening

- Build a reviewed Hindi/Santhali FLN evaluation set.
- Add NIPUN outcome IDs to worksheets/flashcards.
- Add Android UI tests and offline instrumentation tests.
- Benchmark the voice loop on target tablets.

## Full offline AI

- Evaluate smaller/quantized Indic translation models for Android.
- Add an on-device tokenizer/runtime adapter.
- Download model packs only during initial synchronization.
- Verify peak RAM below the target device budget.
- Package deterministic fallback phrase packs for essential classroom instructions.

## Language expansion

- Add Ho language model/data adapter.
- Add Mundari language model/data adapter.
- Add per-language ASR/TTS capability detection.
- Keep shared pedagogy/material-generation interfaces language independent.
