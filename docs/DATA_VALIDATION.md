# Language data and validation

Santhali is a low-resource language, so correct script does not guarantee correct meaning.

## Required review workflow

For every curriculum phrase that will be shipped as trusted classroom content, record:

- Hindi source text.
- Santhali Ol Chiki translation.
- FLN/NIPUN topic and grade.
- Translator/model version.
- Native-speaker reviewer.
- Review date.
- Review status and notes.

## Repository seed pack

The starter pack deliberately contains only two machine smoke-test examples inherited from the earlier prototype. They are marked as requiring native-speaker review; they should not be presented as an expert-validated curriculum dataset.
